- [ ] **[OQ-67]** Help users make room for models (real user reports: not enough disk to install any model). The app detects and declines honestly (`device.rs` free-disk probe, picker `fits_disk`, Storage readout) but does not remediate. **Platform survey (2026-08-12):** iOS — sandbox makes any cleaner impossible; only copy + a pointer to Settings storage. Android — the OS does this safely for us: `StorageManager.allocateBytes(n)` clears *other apps' cached data* to free the requested bytes (system-mediated, we never touch foreign files); plus the system "free up space" intent. macOS — a scan-and-delete cleaner is rejected: it collides with "ask don't sniff" (`06`) and one wrong deletion destroys trust (`CLAUDE.md`, guardian of UX); macOS has its own storage manager — deep-link + honest copy instead. A duplicate-finder is rejected on all platforms for the same reasons (and impossible on iOS/Android anyway). **Decided build order (own sandbox first, never delete a byte we didn't create):** (1) surface + reclaim abandoned `.part` download files (up to ~1.4 GB of dead weight we created — verify Remove covers them); (2) offer "remove the old model?" on picker switch (up to ~1.4 GB); (3) Android `allocateBytes` wired into the "doesn't fit" path; (4) macOS/iOS settings deep-links + copy. Target: ~550 MB free for the minimum experience (Whisper ~140 MB + 0.4 GB chat), ~1.5 GB for the Powerful tier. (From `11-platform-deployment.md`; user reports 2026-08-10.)
